# Wiki Thí Nghiệm - Kho Mô Phỏng Trực Quan K-12

Hệ thống thư viện tri thức tích hợp phòng thí nghiệm mô phỏng trực quan tương tác (Interactive Physics, Math, Chemistry & Biology Simulation Lab) dành cho học sinh phổ thông K-12.

## ✨ Tính năng chính

- 📚 **Phân loại theo Cấp học & Khối lớp**: Tiểu học (Lớp 1 - 5), THCS (Lớp 6 - 9), THPT (Lớp 10 - 12).
- 🔬 **Phòng thí nghiệm mô phỏng trực quan**:
  - *Tiểu học*: Cân đĩa đòn bẩy thăng bằng (Toán & Khoa học).
  - *THCS*: Pha trộn màu sắc & Mô hình sóng ánh sáng (Khoa học tự nhiên).
  - *THPT*: Mạch điện xoay chiều R-L-C & Con lắc đơn / Giải tích dao động vi phân.
- 💡 **Khám phá & Tương tác**:
  - Tùy chỉnh tham số mô phỏng tức thời (Realtime Interactive Canvas & SVG).
  - Khung tra cứu nhanh học thuyết, công thức Toán - Lý - Hóa, định lý (Quick Search).
  - Trình duyệt mã nguồn mô phỏng mẫu (Code Inspector) để học sinh / giáo viên tìm hiểu thuật toán.
  - Hỗ trợ công thức toán học KaTeX.

## 🛠️ Công nghệ sử dụng

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** cho giao diện hiện đại, responsive
- **Lucide Icons**
- **KaTeX** cho công thức toán học

## 🚀 Hướng dẫn cài đặt & khởi chạy

1. Cài đặt các gói phụ thuộc:
```bash
npm install
```

2. Chạy môi trường phát triển (Development server):
```bash
npm run dev
```

3. Đóng gói cho môi trường production:
```bash
npm run build
```
